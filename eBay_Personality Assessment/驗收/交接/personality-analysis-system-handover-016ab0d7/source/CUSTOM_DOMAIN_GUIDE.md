# 自訂網域設定指南

本系統目前使用 Manus 提供的永久網址。若要改用自己的網域，例如 `analysis.example.com`，請在專案管理介面的 **Settings → Domains** 中綁定網域。

## 建議流程

1. 在網域註冊商的 DNS 管理介面新增 Manus 管理介面所提示的 DNS 記錄。通常會是 CNAME 或指定的驗證記錄，請以管理介面顯示的值為準。
2. 回到 **Settings → Domains**，輸入完整網域並完成驗證。
3. 等待 DNS 傳播與 HTTPS 憑證啟用。期間可先保留目前的 `manus.space` 網址作為備援入口。
4. 驗證完成後，使用新的 HTTPS 網址測試公開問卷、`/privacy`、`/admin` 與 `/admin/invite` 路由。

## 注意事項

自訂網域本身不需要修改前端程式碼。若使用 `www` 與根網域兩種入口，建議選擇一個作為主要網址，另一個設定轉址，以避免分享連結分散。管理員邀請連結會使用建立邀請當下的網站來源；切換網域後請重新建立需要分享的新邀請連結。

若要在此專案中直接完成綁定，仍需要您提供要使用的網域名稱，並由您在網域註冊商端完成 DNS 設定；目前未代替您修改任何外部 DNS 記錄。
